# *Nirvana* science fiction cyberpunk style 2D game.

Set in the near future, where artificial intelligence has become deeply integrated into everyday life, the game follows a protagonist navigating a complex world of hackers, powerful corporations, advanced AI, and love.

The game takes place in one European city of the future. 

Inspired by the 1997 film Nirvana, the game explores the boundaries between technology and humanity, and what it means to remain human in an increasingly digital world.

## Structure
The player controls the main character using a keyboard or joystick.

The character can interact with the surrounding world. Additionally, players can use the Lua programming language within the game to create custom programs that can alter and interact with the game world. 


### Usage

To run the app in debug mode:
```
cargo run --features dev
```
